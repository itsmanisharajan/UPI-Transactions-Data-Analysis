# UPI Transactions Data Analysis – Power BI

## Project Overview
Interactive Power BI dashboard analyzing UPI transactions,
transaction amounts, balances, and monthly trends.

## Tools & Technologies
- Power BI
- DAX
- Slicers
- Bookmarks
- Selection Pane
- Data Visualization

## Key Analysis
- Monthly transaction trends
- Transaction amounts and remaining balances
- Bank and city analysis
- Device and demographic analysis
- Merchant and payment method analysis
- Transaction type and purpose analysis
